# KSP Smart Shift & Compensation System
ระบบจัดตารางเวรบุคลากรและคำนวณค่าตอบแทน โรงพยาบาลโคกศรีสุพรรณ

## คุณสมบัติหลัก
- **เชื่อมโยงฐานข้อมูลบุคลากร (`db_hrd`) แบบ Real-time (Read-only)**: ดึงรายชื่อบุคลากร ตำแหน่ง กลุ่มงาน/หน่วยงาน และประวัติการลา (`hrd_leave_data`) พร้อมรองรับการแปลงวันที่ พ.ศ./ค.ศ. อัตโนมัติ
- **เชื่อมโยงข้อมูลไปราชการ (`ksp_travel`)**: แจ้งเตือนอัตโนมัติหากจัดเวรตรงกับวันที่บุคลากรมีคำขออนุมัติไปราชการ
- **ตารางเวร Matrix 31 วัน แบบ Interactive**: Paint-brush ลงเวรเร็ว, รองรับหลายเวรต่อวัน (`เช้า`, `บ่าย`, `ดึก`, `OT`, `On-Call`, `Refer`, `หยุด`), เตือนเวรชนวันลา/ไปราชการ, เตือนความเหนื่อยล้า (`ดึก -> เช้า`, ทำงานติดกัน > 7 วัน), และจัดเวรอัตโนมัติแบบเกลี่ยเวรบ่าย-ดึก
- **คำนวณค่าตอบแทนตามวิชาชีพ (ปรับอัตราได้)**: เวรบ่าย, เวรดึก, OT วันธรรมดา/วันหยุด, On-Call, Refer และเงินเพิ่มรายเดือน (พ.ต.ส., P4P, ไม่ทำเวชปฏิบัติ)
- **ระบบแลกเวร/แทนเวรออนไลน์ & Workflow อนุมัติ**: ร่าง -> ส่งตรวจ -> อนุมัติ -> ล็อกงวด
- **ส่งออกเอกสารทางการ**: พิมพ์ตารางเวรและใบเบิกค่าตอบแทน **PDF (A4 แนวนอน)** และ **Excel (.xlsx)**

## การติดตั้งและพัฒนา (Development)
```bash
cp .env.example .env
# แก้ไขค่า DB_HOST, DB_USER, DB_PASSWORD, SESSION_SECRET ใน .env
npm install
npm --prefix client install
npm run build
npm test
npm start
```
